# AIShe v0.8.0 — every surface reads as one product

AIShe v0.8.0 is a product-quality release. v0.7.0 made the routing decision
explainable; this one makes the rest of the product agree with itself. A
four-part review of the installer, setup, the CLI, the live zsh shell, the
slash-command surface, the agent transcript, and the docs produced 104 findings.
Every one of the 14 that broke a daily path is fixed, and the surface they sit on
now speaks one vocabulary.

This is an alpha, pre-1.0 release. Nothing here changes the safety model: route
decisions, scope grants, and approvals work exactly as they did in v0.7.0.

## Highlights

- Menus launched inside the AIShe shell work. `/settings`, `aishe setup`, and
  `aishe tour` read keys again instead of dying after their first screen.
- Arrow keys move the selection in `/model` and `/connection` instead of
  cancelling the picker and leaking `[B` onto the next prompt.
- A prompt theme is never replaced. powerlevel10k, starship, pure, and a personal
  `PROMPT` survive; the mode glyph moves into the right-prompt status.
- `/usage` reports tokens, prompt-cache hit rate, thinking tokens, turns, model
  time, cost, and plan quota, for this shell, today, and all time.
- The visible slash surface is 20 commands with one six-value effect vocabulary.
  `/help` fits on one screen; `/help all` has the full table.
- Every user-input error is a `cli.*` code with exit 2 and an actionable next
  step, instead of an internal error suggesting a support bundle.
- Setup starts at the first real question and defaults six settings a first-time
  user cannot evaluate.

## Fixed

### The interactive shell

- **Menus inside the shell could not read a keystroke.** `promptui::menu` and the
  hidden secret prompt used a reader bound to `/dev/tty`, which under the
  zsh-PTY front end is the *outer* proxy terminal. `/settings`, `aishe setup`,
  and `aishe tour` painted their first screen, failed with
  `Failed to initialize input reader`, and swallowed the next character typed.
  All prompts now use the same unbuffered inner-PTY reader the pickers use.
- **Arrow keys cancelled the pickers.** Slash commands ran with `< /dev/tty`,
  where AIShe's own input-forwarding loop competes for bytes: it won the race
  after the ESC, so an arrow arrived as a bare Esc and the rest leaked to the
  prompt. zsh dispatch now reads the preserved inner-PTY descriptor. Both CSI
  (`ESC [ B`) and SS3 (`ESC O B`) encodings are covered.
- **Declining the yolo consent prompt raised an internal error.** Any answer but
  the typed word surfaced as `internal.unexpected` with a support-bundle
  suggestion. It is now a cancel that says the mode is unchanged, read in raw
  mode so Esc cancels and Shift-Tab no longer echoes `^[[Z`.
- **The command palette corrupted the prompt.** It painted a frame from inside a
  ZLE widget without invalidating the display, so the buffer was redrawn against
  a stale cursor with no prompt. It also filled CLI forms whose effects differ
  from the slash commands the help teaches, and `/` stayed in the buffer on
  cancel so Enter reopened it.
- **A recognized `/command` wore the error color.** A syntax-highlighting plugin
  reads `/model` as an absolute path that does not exist and paints it the same
  red it gives a genuine typo, so `/model` and `/modle` looked identical. AIShe
  owns the namespace and now claims the span; an unregistered name stays red,
  where red is true.
- **The branded prompt replaced any theme** and set a global `vcs_info` style
  that broke theme git segments, while running `git` on every prompt for a field
  that is not shown by default. Branding now applies only when the zshrc leaves
  zsh's stock prompt in place; `AISHE_PTY_PROMPT=force` overrides.
- **The statusline vanished on narrow terminals** instead of shortening, because
  its budget ignored the real prompt width, counted code points rather than
  cells, and skipped over an over-budget field to render later ones. The mode is
  now the last field dropped.
- **Shift-Tab overrode plugin bindings unconditionally.** It now cycles the mode
  only on an empty line and otherwise runs whatever the user's configuration
  bound, which is what the documentation already claimed. The per-failure
  `--record-failure` spawn no longer blocks the prompt.
- **The bare words `reset` and `details` were intercepted.** `reset` is how a
  garbled terminal is recovered, so it belongs to the user. Use `/reset`,
  `/details`, or Ctrl-O.

### Errors, exit codes, and the CLI

- **Usage errors were reported as internal failures.** A typo'd connection name
  produced `internal.unexpected` and advice to create a support bundle. Input
  errors are now `cli.*` codes with exit 2 and a next step. The three different
  shapes for one unknown-connection error are one shape, fixed at the shared
  root rather than per caller.
- **`aishe … | head` panicked.** The process now restores the default SIGPIPE
  disposition.
- **`aishe -c 'aishe doctor'` printed an internal invariant message** and
  `aishe status --json` silently dropped the flag, because any line beginning
  with `aishe` was intercepted.
- **77 flags and positionals rendered with no description**, worst of all on
  `aishe connection add`. `--json` was phrased 17 ways and is now phrased once.
- **`aishe status` and `aishe doctor` repeated themselves**: the provider named
  twice, `version: version:`, a Debug-formatted terminal policy reading
  `none theme`, a bubblewrap warning on macOS where it does not apply, and the
  same "run `aishe doctor --live`" line on seven rows.
- **`/usage` claimed "provider not configured"** on every managed connection.

### Setup and install

- **Pausing setup reported a broken configuration.** It is now a paused setup
  with the command to resume.
- **The epilogue said "Run: aishe" while the shell was already starting.**
- **Declining the paid live checks was reported as warnings** three times, in the
  review step, the completion summary, and the tour. Skipped checks now say they
  were skipped.
- **"No" at Apply restarted eleven prompts.** It now offers the section to change.
- **The API-key path was unreachable** once an OAuth login existed.
- **The installer's PATH story was wrong on Apple Silicon**, producing three
  contradictory messages and a `command not found`. It now prefers a writable
  Homebrew bin already on PATH, prints the PATH note last with the absolute path,
  and no longer exits non-zero after a successful install without a terminal.

### Agent transcript

- Question and approval panel corners were misaligned on every panel.
- The live activity line counted characters, so a wide path wrapped and left a
  fragment behind.
- The "Ctrl-O details next turn" cue closed every turn forever, including where
  nothing binds Ctrl-O.

### Operations

- **Orphaned runtime servers were invisible.** `aishe backend gc` reported a
  clean cache while parentless loopback OpenCode servers held ports. `doctor`
  now warns and `gc --kill-orphans` stops them.

## Added

- **`/usage` and `aishe usage` are a real report.** Tokens in and out,
  prompt-cache reads and writes as a hit rate, thinking tokens, turns, model
  time, and cost, split by this shell, today, and all time, plus provider plan
  quota where it is exposed. `--by model|connection|day|session`, `--since`,
  `--connection`, and `--json`.
- **A content-free usage ledger** at `<data>/usage.jsonl`: numbers only, no
  prompts, answers, commands, or paths, always written, rotating at 8 MiB with
  one retained generation and mode 0600. The usage report works without enabling
  the content-carrying audit log, which stays opt-in.
- **Cost says which situation you are in.** A subscription reads `plan`, a
  billable model with no configured price reads `no price set`, and a priced
  model reads dollars. All three printed `n/a` before.
- **`aishe backend gc --kill-orphans`** and a `backend.orphans` doctor check.
- **`aishe commands --cli-markdown`** regenerates the CLI table in
  `docs/commands.md`, guarded by a conformance test.
- **`/help all`** prints every visible slash command with its effect.

## Changed

- **The visible slash surface is 20 commands.** Duplicates and maintenance
  commands (`/commands`, `/provider`, `/output`, `/auth`, `/config`, `/skills`,
  `/mcp`, `/palette`, `/resume`, `/fork`, `/task`, `/replan`, `/role`, `/index`,
  `/capabilities`, `/test`, `/demo`, `/trust`, `/untrust`) still dispatch and
  tab-complete but no longer appear in help, the palette, or the docs table.
- **One six-value effect vocabulary** replaces nine derived labels: read-only,
  this shell, this shell with `--default` saving, saves config, conversation, and
  runs agent / edits files. It had called `/ask` "no effect" and `/undo`
  "may change state".
- **The nine 0.6.5 tombstoned names are removed** (`/editor`, `/frontend`,
  `/stream`, `/structured`, `/theme`, `/rehash`, `/ghost`, `/sandbox`, `/cache`),
  freeing them for custom commands, along with the `/help migration` topic.
- **`/help` fits one screen** and an unknown topic exits 2.
- **`aishe provider test` is removed**; use `aishe test`. `demo`, `provider`,
  `models`, and top-level `replan` are hidden aliases.
- **`aishe mode` inside a shell means that shell**, like `/mode`, and
  `--default` saves. Slash arguments reach clap word-split, so
  `/model X --default` works.
- **`/details` cycles all three densities** (focus, compact, detailed) rather
  than flipping between two.
- **The prompt and statusline paint from the same palette as the renderers**, so
  `NO_COLOR`, `TERM=dumb`, and `ui.theme` apply to them. Scope was green in the
  prompt and magenta in an approval panel.
- **One vocabulary in setup**: "Account" rather than "Provider service", one name
  for the agent runtime, `AIShe setup` headers, yes/no prompts ending in a
  question mark, and a completion summary that stops claiming a sandbox macOS
  cannot provide.
- **Setup asks about eight things instead of seventeen**: the endpoint only where
  it varies, and one recommended-defaults row in place of six settings.
- **One cancel word, one prompt footer, one mode message, one `Next:` label**,
  one separator, one focus glyph, and one ellipsis policy that respects the ASCII
  setting.
- The CLI reference in `docs/commands.md` is generated from the clap tree.

## Performance

- The 1000-row picker frame is back inside its 1 ms budget. Routing truncation
  through the glyph policy had made it resolve terminal capabilities per row.

## Compatibility

- No configuration migration. v0.7.0 configs load unchanged.
- Removed: `aishe provider test` (use `aishe test`) and the nine 0.6.5 tombstoned
  slash names, which now behave like any unregistered `/name`.
- Hidden, not removed: `demo`, `provider`, `models`, top-level `replan`, and the
  17 hidden slash aliases all still work.
- `aishe mode <value>` inside an AIShe shell now changes that shell rather than
  writing the default; pass `--default` for the previous behavior.
- The `<data>/usage.jsonl` ledger is new and always written. It is covered by
  `aishe uninstall --audit-undo`.

## Qualification evidence

- `cargo fmt`, `cargo clippy -D warnings`, and `cargo test --all-targets` clean.
- `python3 tests/qualify.py local-full`: 44 gates pass, 0 fail. The 4 skips are
  paid-live and Linux-only gates.
- Eleven new PTY regression tests cover the defects above, each of which was
  previously exercised only by hand: in-shell menus, yolo consent, the palette,
  mode handoff, bare words, prompt themes, keys, statusline width, picker arrows,
  slash highlighting, and the usage report.

## Known limitations

- Plan quota is OpenAI subscriptions only, read through the locally installed
  `codex` CLI over an undocumented local call. A machine without `codex` shows no
  plan line rather than a wrong one.
- `aishe usage` reads the ledger from this release forward; earlier history comes
  from the audit log and only if it was enabled.
- Bash remains Tier B: bash never routes a slash-prefixed word through
  `command_not_found_handle`, so slash commands reach AIShe through the ERR-trap
  fallback.
